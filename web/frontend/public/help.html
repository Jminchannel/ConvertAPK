安全打包指南

这里说明 ConvertAPK 的常见使用方式、支持文件、签名建议和构建失败排查方法，帮助你更稳定地生成 APK/AAB。

目录 支持的输入 推荐流程 签名与版本 日志排查 安全要求

支持的输入

  • 前端项目 ZIP：适用于常见 React、Vue、Vite 等 Web 项目。
  • 网站地址：适用于你拥有或已获授权打包的网站。
  • HTML 文件：适用于单文件页面、轻量演示和离线页面。
  • 桌面端项目 ZIP：适用于需要打包为 Windows 桌面应用的前端项目。

推荐流程

  • 先确认项目能在本地浏览器正常运行，避免上传缺少入口文件或依赖的压缩包。
  • 填写清晰的应用名称、包名、版本号和输出格式。
  • 构建后先查看日志，再下载产物进行安装测试。
  • 准备上架前，额外检查权限、隐私政策、图标、截图和应用商店声明。

签名与版本

Android 应用需要稳定的包名和版本号。准备长期维护或上架时，请妥善保存自己的签名证书，后续更新通常必须使用同一证书。

AAB 更适合 Google Play 发布，APK 更适合直接安装和内部测试。

日志排查

如果构建失败，请优先查看日志中的依赖安装、入口文件、Android SDK、Gradle、签名配置和网络下载错误。反馈问题时，可以附上错误摘要和截图。

安全要求

请勿上传破解、盗版、恶意软件、钓鱼页面、绕过授权或侵犯第三方权利的内容。本服务会围绕合法打包和用户安全持续调整限制。
